# QNAV — Quantum Navigation Visualization Platform

QNAV is an interactive web application built to demonstrate and visualize the complete workflow of an NV-center–based quantum navigation system. The platform combines navigation simulation, magnetic field sensing, machine learning, and interactive 3D visualization into a single browser-based interface.

The project focuses on demonstrating how an ensemble of NV-center sensors can be used to measure the Earth's magnetic field, reconstruct magnetic signatures, and estimate the position of a moving receiver using machine learning models.



# Project Overview

The application is organized into several interconnected modules representing different stages of a quantum navigation system.

## Mission Control

Acts as the central dashboard of the application.

Features include:

- Navigation system overview
- Live simulation status
- Vehicle summary
- Sensor configuration summary
- Dataset information
- Quick access to all modules



## Vehicle & Motion

Configure the simulated receiver before starting a navigation mission.

Supported vehicle types include:

- Ground Vehicle
- Aircraft
- Drone
- Ship

Vehicle parameters:

- Vehicle type
- Speed
- Altitude
- Climb rate
- Turn rate

Each vehicle automatically enforces realistic operating limits for speed and altitude.


## Location & Route

Interactive geographic route planning using real-world maps.

Features:

- World map visualization
- Click-to-place waypoints
- Multiple waypoint support
- Editable latitude and longitude coordinates
- Automatic route generation
- Animated map zoom
- Geographic trajectory visualization


## Sensor Ensemble

Interactive visualization of the NV-center sensor array.

Features:

- 3D sensor arrangement
- Diamond orientation visualization
- Configurable number of NV diamonds
- Sensor geometry controls
- Automatic rotation
- Drag-to-rotate interaction
- Sensor configuration preview
- Live sensor parameter updates

The visualization demonstrates how multiple NV-center orientations contribute to magnetic field measurements.



## Magnetic Field Analysis

Visualizes the magnetic-field reconstruction process.

Includes:

- Ground truth magnetic field
- Reconstructed magnetic field
- Reconstruction error
- Time-based analysis
- Interactive charts



## Position Estimation

Machine learning–based receiver position estimation.

The interface visualizes predictions generated by the external **NV_ML** pipeline.

Current regression model:

- Physics-Informed Transformer (with uncertainty estimation and EKF fusion)

Predicted quantities:

- Latitude
- Longitude
- Altitude

The module includes:

- Machine learning pipeline overview
- Interactive 3D trajectory viewer
- Actual vs predicted receiver trajectory
- Current receiver position
- Predicted receiver position
- Position comparison charts
- Latitude comparison
- Longitude comparison
- Altitude comparison
- Position error visualization
- 3D Euclidean error
- Interactive playback controls
- Simulation time slider
- Feature importance
- Model evaluation metrics

## 3D Trajectory Visualization

Receiver trajectories are displayed inside an interactive Three.js scene.

The visualization includes:

- Actual trajectory
- Predicted trajectory
- Current actual position
- Current predicted position
- Error connector
- Animated playback

Geographic coordinates are converted into a local Cartesian coordinate system for visualization while preserving relative spatial relationships.

Coordinate system:

- X → East
- Y → Altitude
- Z → North

## Simulation

QNAV provides an interactive time-based simulation system.

Users can:

- Play simulation
- Pause simulation
- Reset simulation
- Move to any simulation timestamp
- Inspect receiver positions throughout the trajectory

Changing the simulation time updates:

- Current receiver position
- Predicted receiver position
- Latitude
- Longitude
- Altitude
- Position errors
- 3D trajectory
- Error indicators
- Charts

## Data Export

Simulation outputs can be exported for further analysis.

Supported formats:

- CSV
- JSON

Exported data may include:

- Navigation parameters
- Vehicle information
- Sensor measurements
- Magnetic field values
- Receiver trajectory
- Position estimates

# Purpose

QNAV was developed as a visualization platform for exploring quantum navigation concepts based on NV-center magnetometry. It integrates navigation simulation, interactive mapping, sensor visualization, magnetic-field analysis, and machine learning–based position estimation into a unified web application for research, demonstration, and educational purposes.
